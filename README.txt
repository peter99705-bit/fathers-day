# 父親節網站｜給老爸

## 你需要修改的地方

### 1. 爸爸照片
把爸爸照片放進 `images` 資料夾，並命名：
- dad.jpg
- memory1.jpg
- memory2.jpg
- memory3.jpg
- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg

不一定要全部使用；如果沒有某張照片，網站會顯示預設提示圖。

### 2. 回憶年份與故事
打開 `index.html`，搜尋：
`【需要修改】`
把附近的年份、標題、故事改成你們自己的回憶。

### 3. 給爸爸的信
搜尋：
`老爸，其實我平常很少把「謝謝」說出口。`
把整段換成你真正想對爸爸說的話。

### 4. 爸爸的特點
搜尋：
`總是很努力`
`遇到事情很可靠`
等文字，改成真正符合你爸爸的描述。

### 5. 最後祝福
搜尋：
`父親節快樂，老爸`
可以改成你自己的句子。

## 怎麼開啟
1. 安裝 VS Code
2. 用 VS Code 開啟這個資料夾
3. 安裝 Live Server 擴充功能（推薦）
4. 對 `index.html` 按右鍵 → Open with Live Server

也可以直接雙擊 index.html 開啟。

## 想放背景音樂
建立 `music` 資料夾，放入 `music.mp3`。
然後打開 `script.js`，把最下面的音樂程式取消註解。

注意：瀏覽器通常不允許網頁一開啟就自動播放音樂，所以建議讓爸爸按右上角的 ♫ 按鈕開始播放。
